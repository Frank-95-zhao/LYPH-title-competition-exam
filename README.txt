LYPH 职称竞聘题库 · PWA v5（质量重构版）

功能：
- 10 个独立题库，可按模块直接选择
- 1,246 道通过自动质量门槛的题（1,161 单选 + 85 多选）
- 分类入口打开该类别全部题目；学习计划单独保留每日 50 题
- 单选题和多选题即时判分
- 上一题 / 下一题按钮
- 未作答也可前后切题；iPhone 右滑上一题、左滑下一题
- 题号面板支持在该类别全部题目中直接跳转
- 错题本、分模块统计和本机学习记录
- 独立学习计划页面，首页不显示“14天强化”
- PWA 主屏幕安装与离线使用
- 自动迁移旧版 doctorLawExam_v1 医师法记录

文件：
- index.html：页面结构
- styles.css：页面样式
- app.js：刷题、记录迁移和手势逻辑
- data/questions.json：10 类题库索引
- data/questions/：按模块拆分的 10 个题库数据文件
- manifest.webmanifest：PWA 清单
- sw.js：离线缓存
- icons/：iPhone 主屏幕图标

iPhone 使用：
1. 用 Safari 打开 GitHub Pages HTTPS 地址。
2. 点底部“分享”。
3. 选择“添加到主屏幕”。
4. 首次联网完整打开后，即可在断网时继续使用。

数据说明：
学习记录只保存在当前浏览器的 localStorage 中，不会自动上传。
题库依据用户提供的 10 份考试材料生成；作答后在解析中显示原文出处，作答前不显示条款编号。
