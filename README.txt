LYPH 职称竞聘题库 · PWA v4（逐知识点覆盖版）

功能：
- 10 个独立题库，可按模块直接选择
- 1,810 个独立知识点，3,885 道题（3,670 单选 + 215 多选）
- 每个独立知识点至少对应 2 道单选，列举型条款另有多选题
- 每轮最多 50 题，未做题优先并穿插错题
- 单选题和多选题即时判分
- 上一题 / 下一题按钮
- iPhone 右滑上一题、左滑下一题
- 错题本、分模块统计和本机学习记录
- 独立学习计划页面，首页不显示“14天强化”
- PWA 主屏幕安装与离线使用
- 自动迁移旧版 doctorLawExam_v1 医师法记录

文件：
- index.html：页面结构
- styles.css：页面样式
- app.js：刷题、记录迁移和手势逻辑
- data/questions.json：10 类题库数据
- manifest.webmanifest：PWA 清单
- sw.js：离线缓存
- icons/：iPhone 主屏幕图标

iPhone 使用：
1. 用 Safari 打开 GitHub Pages HTTPS 地址。
2. 点底部“分享”。
3. 选择“添加到主屏幕”。
4. 首次联网完整打开后，即可在断网时继续使用。

数据说明：
学习记录只保存在当前浏览器的 localStorage 中，不会自动上传。
题库依据用户提供的 10 份考试材料生成；每题保留原文出处与条款编号。
